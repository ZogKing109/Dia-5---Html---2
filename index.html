JavaScript é uma linguagem de programação interpretada, amplamente usada para o desenvolvimento web. Ela permite criar páginas dinâmicas e interativas, rodando diretamente no navegador do usuário. Além do front-end, com o Node.js, o JavaScript também é utilizado no back-end, possibilitando o desenvolvimento de aplicações completas. É uma linguagem de tipagem dinâmica, orientada a objetos e baseada em eventos, essencial para a experiência moderna na web.

Python

Python é uma linguagem de programação de alto nível, interpretada e de tipagem dinâmica, conhecida por sua simplicidade e legibilidade. Criada por Guido van Rossum e lançada em 1991, Python é amplamente utilizada em diversas áreas, como desenvolvimento web, ciência de dados, inteligência artificial, automação, entre outras.

Java

Java é uma linguagem de programação orientada a objetos, criada em 1995 pela Sun Microsystems, que se destaca pela portabilidade graças à Java Virtual Machine (JVM), permitindo que o mesmo código seja executado em diferentes plataformas sem modificações. Com uma sintaxe inspirada em C++, Java oferece uma estrutura robusta e segura, ideal para desenvolver aplicações empresariais, sistemas web, e apps móveis, especialmente para Android. Além disso, sua vasta biblioteca padrão e o forte suporte da comunidade tornam Java uma das linguagens mais populares e versáteis no desenvolvimento de software atualmente.

HTML

HTML (HyperText Markup Language) é a linguagem padrão utilizada para estruturar e organizar o conteúdo na web. Por meio de uma série de elementos e tags, o HTML define a estrutura básica de páginas web, como títulos, parágrafos, imagens, links e listas, permitindo que navegadores interpretem e exibam o conteúdo de forma organizada. Embora não seja uma linguagem de programação, HTML é essencial para o desenvolvimento front-end, funcionando em conjunto com CSS e JavaScript para criar páginas interativas, visuais e funcionais na internet.
